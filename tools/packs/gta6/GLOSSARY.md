# GTA VI sözlüğü

Bu dosya `tools/packs/glossary/gta6.json`'dan `gta6glossary_md.py` ile üretilir; elle düzenlenmez.
Değişiklik önerisi için `AGENT_WORKFLOW.md` → "Sözlük değişikliği".

Kaynak: gta-v paketi (GTA TR (TechnoGame) + Claude Haiku 5.5), 190566 satır; API kullanılmadı.

## Hitap kuralı

Varsayılan 'sen'; 'siz' yalnız resmî hitapta (polis, görevli, yabancı yetişkin). Küfür aynı şiddette kalır. Arayüz yazıları (ÖLDÜN, YAKALANDIN) GTA V paketindeki gibi büyük harf.

## Aynen kalanlar

Bu isimler çevrilmez; Türkçe ekler kesme işaretiyle eklenir (Lucia'yı, Vice City'de).
